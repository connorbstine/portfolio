# Connor Stine

Personal site: portfolio, projects, and a personal multitool.

Live at https://connorbstine.github.io/portfolio/

## Editing content

All cards live in the `ITEMS` list near the top of the script in `index.html`.
Each item has a `tab` (portfolio, projects, tools), a `group` (section heading), a title, a description, a tag and an optional link.
Change `tab` or `group` to move a card. A new group name makes a new section.

## Swarm intro

- Visitors get a welcome menu: "Watch it build" or "Skip to the site", with "Remember my choice".
- Turn it off for everyone: set `window.SWARM_ENABLED = false` at the top of `index.html`.
- It stays off for anyone with "Reduce motion" turned on.
- Cursor count, speed, names and colors live in `CONFIG`.
